Проверка API через curl, 18.11.2026
Временная SQLite-база. Пароль и JWT в записи скрыты.

$ curl "$BASE/auth/login" -H "Content-Type: application/json" -d '{"username":"alice","password":"<скрыт>"}'
{"access_token":"<JWT скрыт>","expires_in":900,"token_type":"Bearer"}

HTTP 200

$ curl "$BASE/api/data" -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{"text":"Моя заметка"}'
{"id": 1, "text": "Моя заметка"}
HTTP 201

$ curl "$BASE/api/data" -H "Authorization: Bearer $TOKEN"
[{"id": 1, "text": "Моя заметка"}]
HTTP 200

$ curl "$BASE/api/data"
{"error": "Требуется Bearer-токен"}
HTTP 401
